## 6. 规定问题回答

**Q1 知识库扩大后 BM25 是否下降？** 没有下降。离线全量 BM25 分块 Recall@5 70.4%，高于 RRF（68.4%）与向量方案（54.1%，离线为本地哈希）。原因是权威法规条文含大量条文号、数字与专有名词，词面精确匹配占优。需注意：无答案正确拒答率仅 16.7%，扩大语料使相似条文更易被误匹配，这是另一维度的退化。
**Q2 真实 Embedding 对同义改写、多跳是否提升？** 离线（本地哈希向量）未见提升：同义改写 Recall@5 由 BM25 75.0% 降至向量 50.0%，多跳由 100.0% 降至 50.0%。在线小样本（真实 Embedding）中同义改写 Recall@5 100.0% 高于 BM25 50.0%，但样本仅 2 条，不足以证明稳定收益；且真实 Embedding 平均延迟约 214.84ms，远高于 BM25。**结论：暂无可信证据支持真实 Embedding 在这两类问题上优于 BM25。**
**Q3 Reranker 是否改善证据排序，还是引入排序损失？** 离线几乎无改善（MRR@5 0.5259→0.5252），在线小样本 MRR@5 由 0.5000 升至 0.6000，但 P95 延迟由 327.34ms 增至 625.73ms。综合判断：未观察到稳定的重排收益，且延迟代价显著。
**Q4 真实 LLM 是否比确定性摘录更准确、更完整？** 在线复核批次中 31 条由真实 LLM 生成、5 条走确定性兜底。自动事实要点覆盖：LLM 100.0%，离线确定性摘录 79.7%；但该启发式会饱和（35/36 条为 100%，其中 5 条实为整段摘录），也误判过正确改写（v4-q-011 判 0），**不能作为质量结论**。可确认的是：LLM 答案更接近自然表述、能合并多来源并给出引用；确定性兜底在证据门禁未通过时会输出整段无关条文（v4-q-035 即摘到错误法规）。是否更准确、更完整，须待 36 条人工复核完成后判定。
**Q5 哪种方案在质量/延迟/成本间最值得部署？** 当前证据下 **BM25（方案 A）** 最稳妥：离线质量最高、延迟最低、无外部 API 成本。真实 Embedding 与 Reranker 未带来稳定质量提升，却引入 200~700ms 级延迟与持续调用成本，不建议默认启用；如需改善拒答，应优先改证据门禁策略（本轮按要求不做算法重构）。
