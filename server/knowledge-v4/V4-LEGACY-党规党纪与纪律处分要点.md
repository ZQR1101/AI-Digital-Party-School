# 党规党纪与纪律处分要点

## 《中国共产党纪律处分条例》核心内容与六项纪律

党的纪律是党的各级组织和全体党员必须遵守的行为规则。《中国共产党纪律处分条例》明确将党的纪律划分为六大门类：

1. **政治纪律**：
   - 最重要、最根本、最关键的纪律。
   - 坚决维护党中央权威和集中统一领导，在重大原则问题上同党中央保持高度一致，严禁妄议党中央大政方针，严防搞团团伙伙、结党营私。

2. **组织纪律**：
   - 坚持民主集中制原则，严格执行请示报告制度，严格落实领导干部个人有关事项报告制度，服从组织安排与调动。

3. **廉洁纪律**：
   - 严禁违规收送礼品礼金、违规接受宴请、违规从事营利活动，严禁公款旅游或借机吃喝，坚决抵制享乐主义和奢靡之风。

4. **群众纪律**：
   - 站稳人民立场，严禁侵害群众利益、克扣群众财物，坚决整治群众身边不正之风和腐败问题，切实解决群众急难愁盼。

5. **工作纪律**：
   - 勇于担当作为，坚决反对形式主义、官僚主义，严禁不作为、慢作为、乱作为，严格遵守保密纪律与考试工作规范。

6. **生活纪律**：
   - 践行社会主义核心价值观，注重家庭家教家风建设，不得违反社会公序良俗，抵制不良嗜好。

## 党员纪律处分种类与适用

对党员的纪律处分种类共有五种：
1. **警告**：一年内不得在党内提升职务和向党外组织推荐担任高于其原任职务的党外职务。
2. **严重警告**：一年半内不得在党内提升职务和向党外组织推荐担任高于其原任职务的党外职务。
3. **撤销党内职务**：撤销其由党内选举或任命的党内职务，二年内不得在党内担任和向党外组织推荐担任与其原任职务相当或者高于其原任职务的职务。
4. **留党察看**：分为留党察看一年、留党察看二年，期间党员无表决权、选举权和被选举权。
5. **开除党籍**：党内的最高处分，五年内不得重新入党。
