# 中央八项规定精神与作风建设要点

## 中央八项规定主要内容

2012年12月，中共中央政治局会议审议通过《十八届中央政治局关于改进工作作风、密切联系群众的八项规定》，主要包括：

1. **改进调查研究**：到基层调研要深入了解真实情况，多到实地走访，减少陪同，简化接待。
2. **精简会议活动**：切实改进会风，严格控制会议数量、规模和时间，能不开的会坚决不开。
3. **精简文件简报**：切实改进文风，没有实质内容的文件简报一律不发。
4. **规范出访活动**：严格控制出访随行人员，严格按照规定乘坐交通工具。
5. **改进警卫工作**：减少交通管制，一般情况下不得封路、不清场闭馆。
6. **改进新闻报道**：根据工作需要、新闻价值、社会效果决定是否报道，进一步压缩报道数量、字数和时长。
7. **严格文稿发表**：除中央统一安排外，个人不公开出版著作讲话单行本，不发贺信、贺电，不题词、题字。
8. **厉行勤俭节约**：严格遵守廉洁从政有关规定，严格执行住房、车辆配备等有关工作和生活待遇的规定。

## "四风"问题的表现

"四风"是指形式主义、官僚主义、享乐主义和奢靡之风，是违背党的性质和宗旨的突出问题，是作风建设的重点整治对象。

- **形式主义**：重痕迹轻实效，以文件落实文件、以会议落实会议，搞材料出政绩。
- **官僚主义**：脱离群众，高高在上，推诿扯皮，不作为、慢作为、乱作为。
- **享乐主义**：精神懈怠，贪图安逸，讲究排场，追求感官享受。
- **奢靡之风**：铺张浪费，违规公款消费，违规收送礼品礼金，追求奢华。

## 作风建设常态化要求

1. 坚持问题导向，紧盯重要时间节点，防止"四风"问题隐形变异、反弹回潮。
2. 党员领导干部要带头执行廉洁自律准则，如实报告个人有关事项。
3. 基层党组织要把作风建设纳入组织生活会和民主评议党员的重要内容。
4. 对违反中央八项规定精神的问题坚持露头就打、从严查处，点名道姓通报曝光。
