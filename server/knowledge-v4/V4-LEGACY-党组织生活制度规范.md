# 党组织生活制度规范与工作指南

## 组织生活会与民主生活会的区别

组织生活会与民主生活会是党内政治生活的重要载体，两者在参加主体、召开层级、会议目的和召开频次上存在明确区别：

1. **参加主体与召开层级不同**：
   - **组织生活会**：是党支部或党小组开展党内政治生活的基本形式，参加对象为党支部全体党员，包括在该支部参加组织生活的党员领导干部，属于支部基层层面的组织生活。
   - **民主生活会**：主要在县以上党和国家机关党员领导干部、企事业单位领导班子、基层党委及党总支领导班子成员中召开，是领导班子成员专属的高层党内政治生活。

2. **会议主要目的与内容不同**：
   - **组织生活会**：重点围绕党支部党员个人的思想、工作、学习和作风情况，查摆自身存在的差距和不足，开展严肃认真的批评与自我批评，进行党性分析，增强党支部凝聚力和战斗力。
   - **民主生活会**：重点围绕贯彻执行党的基本路线、落实全面从严治党政治责任、执行中央八项规定精神、班子团结协作和廉洁自律等全局性重大问题进行对照检查和检视剖析。

3. **召开频次与程序要求**：
   - **组织生活会**：党支部每年至少召开一次组织生活会，通常结合年底民主评议党员开展，也可根据实际需要随时召开。
   - **民主生活会**：通常每年召开一次，一般安排在第四季度或次年年初进行，需制定详尽方案并报上级党组织审批。

4. **制度政策依据**：
   - 《中国共产党章程》第八条明确党员必须参加党的组织生活。
   - 《关于新形势下党内政治生活的若干准则》对坚持民主生活会和组织生活会制度作出了系统规定。
   - 《中国共产党支部工作条例（试行）》第二十一条对党支部组织生活会的形式和程序作出了具体规定。

## “三会一课”制度规范

“三会一课”是指定期召开支部党员大会、支部委员会会议、党小组会，按时上好党课。

1. **支部党员大会**：
   - 每季度至少召开一次。
   - 主要任务：传达学习党的路线方针政策；听取和审查支部委员会工作报告；讨论通过发展党员、转正和处分党员；选举支部委员会等。

2. **支部委员会会议**：
   - 每月至少召开一次。
   - 主要任务：研究贯彻上级指示；讨论研究支部建设、党员教育管理监督和各项重点任务落实。

3. **党小组会**：
   - 每月至少召开一次。
   - 主要任务：组织党员学习；讨论党员思想和工作实际；开展批评与自我批评。

4. **党课**：
   - 每季度至少组织一次。
   - 党课内容应贴近党员思想和工作实际，由党组织书记、党员领导干部或优秀党员主讲。

## 谈心谈话与民主评议党员制度

1. **谈心谈话**：党支部应当经常开展谈心谈话，党支部书记与支部委员、支部委员之间、支部委员与党员之间、党员与党员之间每年至少谈心谈话一次。
2. **民主评议党员**：结合组织生活会每年开展一次，按照个人自评、党员互评、民主测评、组织评定的程序进行，评定结果分为优秀、合格、基本合格、不合格四个等次。
