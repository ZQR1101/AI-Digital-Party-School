# 党的基层组织建设与换届选举工作指南

## 党的基层组织设置

党的基层组织是党在社会基层组织中的战斗堡垒，是党的全部工作和战斗力的基础。党的基层组织包括基层党委、党总支和党支部。凡是有正式党员三人以上的，都应当成立党的基层组织。

党的基层委员会每届任期三年至五年，总支部委员会、支部委员会每届任期三年至五年。基层委员会、总支部委员会、支部委员会选出的书记、副书记，应报上级党组织批准。

## 党支部的主要职责

1. 宣传和执行党的路线方针政策，宣传和执行党中央、上级组织和本组织的决议，充分发挥党员先锋模范作用，团结组织党内外的干部和群众，努力完成本单位所担负的任务。
2. 组织党员认真学习党的创新理论和党的基本知识、科学知识、业务知识。
3. 对党员进行教育、管理、监督和服务，提高党员素质，坚定理想信念，增强党性，严格党的组织生活，开展批评和自我批评。
4. 密切联系群众，经常了解群众对党员、党的工作的批评和意见，维护群众的正当权利和利益，做好群众的思想政治工作。
5. 领导党员和群众抵制不良风气，同违法犯罪行为作斗争。
6. 按照标准和程序发展党员，重视培养、选拔和推荐优秀党员担任党内职务。

## 支部委员会换届选举程序

1. **请示报批**：支部委员会任期届满前，应向上级党组织提出换届请示，经批准后开始筹备。
2. **酝酿候选人**：组织党员充分酝酿，根据多数党员的意见提出候选人预备人选，报上级党组织审查同意。
3. **召开党员大会**：有选举权的到会党员人数须超过应到会党员人数的五分之四方可进行选举。候选人获得的赞成票超过应到会有选举权人数半数方可当选。
4. **选举支委委员**：由党员大会差额选举产生支部委员会委员。
5. **选举书记副书记**：新一届支部委员会第一次全体会议选举书记、副书记，报上级党组织批准。
6. **报批结果**：将选举结果报上级党组织审批，获批后新一届支委正式履职。

## 党小组的设置与作用

党小组是党支部的组成部分，不是党的一级组织。党小组在支部委员会领导下开展工作，主要负责组织党员学习、分配每个党员的工作、监督党员履行义务、开展谈心谈话和批评与自我批评。党小组长由本小组党员选举产生或由支部委员会指定。
