# 党员组织关系与党籍管理实务

## 党员组织关系的含义

党员组织关系是指党员对党的基层组织的隶属关系。党员必须编入党的一个支部、小组或其他特定组织，参加党的组织生活，接受党内外群众的监督。每个党员都必须隶属于一个党组织，不得脱离组织。

## 组织关系转接

1. **转接情形**：党员工作单位、经常居住地发生变动，或者外出学习、工作、生活六个月以上且地点比较固定的，应当转移组织关系。
2. **转接凭证**：党员组织关系凭证是党员组织关系转接的证明。省内转接一般通过全国党员管理信息系统进行，无需纸质介绍信。
3. **办理时限**：党员应当及时办理组织关系转接手续，接收单位党组织应及时将党员编入相应支部并告知本人。
4. **预备党员转接**：预备党员在预备期内转移组织关系的，其预备期继续计算，接收党组织应继续对其进行培养教育和考察。

## 党籍管理

党籍是指党员资格。从支部大会接收预备党员之日起，即取得党籍。

1. **党龄计算**：党员的党龄，从预备期满转为正式党员之日算起。预备党员没有党龄。
2. **组织关系保留**：党员外出务工、经商或到其他单位工作，组织关系一般应随同转移；短期外出或外出时间较长但地点不固定的，可保留组织关系。
3. **停止党籍**：对因私出国（境）长期定居、失联等原因的党员，经党组织研究可按规定停止党籍，停止党籍后不得参加党的组织生活，不享有党员权利。
4. **自行脱党处理**：党员如果没有正当理由，连续六个月不参加党的组织生活，或不交纳党费，或不做党所分配的工作，就被认为是自行脱党。支部大会应当决定把这样的党员除名，并报上级党组织批准。
