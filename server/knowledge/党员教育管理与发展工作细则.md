# 党员教育管理与发展工作细则

## 发展党员工作流程与关键环节

发展党员工作贯彻“控制总量、优化结构、提高质量、发挥作用”的总要求，严格遵循五个阶段：

1. **申请入党阶段**：
   - 年满十八岁的中国工人、农民、军人、知识分子和其他社会阶层的先进分子向党组织递交入党申请书。
   - 党支部在一个月内派人同入党申请人谈话。

2. **入党积极分子的确定和培养教育阶段**：
   - 支部委员会听取党小组、培养联系人、党员和群众意见后确定积极分子。
   - 确定一至两名正式党员作为培养联系人，培养教育时间一般在一年以上。

3. **发展对象的确定和考察阶段**：
   - 经一年以上培养教育，听取党小组和群众意见，支部委员会综合考察后列为发展对象。
   - 开展严格的政治审查和集中培训（培训时间通常不少于3天或24个学时）。

4. **预备党员的接收阶段**：
   - 支部大会讨论接收预备党员，有表决权的正式党员过半数赞成方可通过决议。
   - 报上级党委审批，党委审批意见在一个月内批复。

5. **预备党员的教育、考察和转正阶段**：
   - 预备期为一年。预备党员预备期满时，应提前一周向党支部提出书面转正申请。
   - 支部大会讨论转正决议并报上级党委审批。

## 党员日常教育与学时学分管理

1. 党员每年参加集中培训和集体学习时间一般不少于32学时，基层党组织书记和班子成员不少于56学时。
2. 结合数智党校系统开展线上课程必修与选修，日常学习完成率纳入党员民主评议与评优考评范畴。
